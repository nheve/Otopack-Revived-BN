# Otopack-Revived-BN
This is a Cataclysm - Bright Nights version of Otopack soundpack forked from Kenan2000, also inspired by now deleted Otopack 2 by RoyalFox. Otopack-Revived-BN is maintained by nheve, and is open to new pull requests from any upcoming contributors. Support for CDDA is not guaranteed in this version at all. Main goal is to preserve this soundpack, and to provide fixes, new additions and support for mods in the future.

## Music (removed) 
All the music previously found in Kenan's fork was removed due to unknown copyright status and lack of contact to the original authors. It's also done to reduce the size of the soundpack as a base of this fork.

## Prerequisites 
None

## Installation
**1)** Press the [`Releases`](https://github.com/Kenan2000/Otopack-Mods-Updates/releases) button, you'll get to page with releases where source code of "Otopack-Revived-BN" release is available for downloading, download source code of "Otopack-Revived-BN", but keep in mind that if you pause downloading then you will have to download it from the beginning again;

**2)** Put the entire "OtopackRevivedBN" folder inside of `cbn/data/sound/`directory, or if you are using Catapult launcher, put the folder inside of `Catapult/bn/userdata/sound/` directory;

**3)** Launch the game and enable the soundpack in the `settings` of the game;

## Updating the soundpack
Simply download source code of latest release, erase older version of "Otopack-Revived-BN" in your game folder, put source code of my uploaded, updated soundpack release inside of `cbn/data/sound/` directory (or `Catapult/bn/userdata/sound/` for Catapult launcher), enjoy the soundpack :)
