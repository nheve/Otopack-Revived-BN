# Otopack Revived BN

This is a Cataclysm - Bright Nights version of Otopack soundpack forked from Kenan2000, also inspired by now deleted Otopack 2 by RoyalFox. Otopack-Revived-BN is maintained by nheve, and is open to new pull requests from any upcoming contributors. Support for CDDA is not guaranteed in this version at all. Main goal is to preserve this soundpack, and to provide fixes, new additions and support for mods in the future.

To install, put the Otopack folder containing this readme in '<CBN Folder>\data\sound\' directory, or if you are using Catapult launcher: '<Catapult>/bn/userdata/sound/' directory, and then select it from the settings menu.
If you're a mobile player and your device is low on RAM, you might not be able to use this soundpack.
